# Project 1 - NYC Taxi Analytics Platform

## Overview
This project demonstrates an end-to-end analytics and data engineering solution using NYC taxi trip data. The goal is to build a business-ready data platform that ingests raw trip records, transforms them into curated analytical datasets, applies data quality checks, and supports dashboard reporting for operational and business insights.

## Objectives
- Build a raw-to-curated data pipeline
- Design business-focused KPI tables
- Apply data quality validation
- Analyze trip demand, revenue, and zone performance
- Create a flagship portfolio project for data engineering and analytics roles

## Core Skills Demonstrated
- SQL
- Python
- Data modeling
- Data quality checks
- Pipeline design
- Business KPI development
- Dashboard-ready analytics
